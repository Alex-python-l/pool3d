# 整合版几何与显示约定

本阶段采用 V3 的 2540×1270 mm 台面、57.15 mm 球径、1450 mm 球杆及 12.5 mm 皮头；不是完整标准中式袋口。配置为 `UnityProject/Assets/StreamingAssets/TableGeometry.json`，每局在 reset 前验证并复制，规则、AI 和显示读取局内快照。

## 坐标与锚点

- 模拟 x/y 是台面长/短轴，z 是球心相对静止高度；默认 1 模拟单位=0.001 m。
- 显示保留旧厘米比例：`world=(0.1*sim.y,0.1*sim.z,0.1*sim.x)`；反变换 `(10*world.z,10*world.x,10*world.y)`。
- V3 环境米制根缩放 100，布面移到 world Y=-2.8575；静止球心 Y=0。球网格为 V3 半径 1 的专用 UV 球，运行时缩放 2.8575。
- 击球点左正、高正；显示使用与物理相同的接触点投影。皮头按球面截面到母球表面，静止间隙 3 mm，满后拉 200 mm。球杆显示根 forward 表示瞄准方向，不以偏移后的杆中心反推方向。
- 原球旋转置换保留 `(qx,qy,qz,qw) -> (qy,qz,qx,qw)`，不新增 Rigidbody 球体运动。

## 碰撞包络来源

`IntegrationBaseline.Run` 只读取本工程导入的 `PoolTable_Chinese.fbx`，将 11 个 Mesh 的顶点和三角形保存为 `table_mesh_export.json`。`Source/build_geometry.py` 对 `PoolSet_Bumper` 三角形作台面投影，拼接六块库边的二维轮廓，再简化到原碰撞引擎可以消费的线段。

首四段为外侧保护边界，4–9 为六段主库鼻，余下为袋口斜面及库边背部投影。当前共 31 段，碰撞缓存按数量扩容。源投影边界采样 3216 点，最大轮廓偏差约 0.00118 mm；详见 `geometry_mesh_report.json`。

这是几何投影一致性，不是库鼻三维碰撞标定：网格库鼻高约 34.95 mm，物理仍按既有二维平面球模型处理，没有新增垂直冲量、跳球或抬杆。

## 袋口与摆球

- 六袋编号保持原逻辑顺序：长轴负端/短轴正侧角袋、正侧中袋、长轴正端/正侧角袋、正端/负侧角袋、负侧中袋、负端/负侧角袋。
- 袋中心来自对应 Pocket 网格上沿包围盒；继续采用原圆形中心捕获。捕获半径取袋上沿内接半径减去球半径，约 51.81 mm；此策略有明确来源，但尚未经用户碰袋手感验收。
- 新头线 X=-635，初始母球 X=-900，球堆基点 X=635，9 球重置目标球点 X=635；球堆间距仍由球径生成，未随桌面整体拉伸。
- AI 只替换几何输入和局内缓存：袋口目标、反射平面、自由球采样及障碍线段。原决策、力度估算、历史分支保留，未调优新系数或主动加塞。

## 制作与验收边界

编辑模式检查只操作数值、独立显示对象和相机投影矩阵；没有构造游戏宿主、AI 实例、对局或执行模拟 tick。场景可静态保存，球组与游戏相机由启动器在用户运行时组装。

本阶段没有启用 V3 静态四球细绒、沿用旧样板 LightingData 或烘焙新光照。基底短绒材质已将厘米世界坐标换米采样；完整动态细绒、GI/反射、正式后处理和 Windows 包在后续 M2/M3 完成。
