## 边界与下一步

本轮已完成的是 Blender 中的实物资源与击球视角预览。Unity 运行时球杆/相机、拉杆出杆动作和游戏规则绑定尚未执行，不能把本轮截图称为已经可玩的新游戏。

具体工作见 **`Unity接入实施方案.md`**：沿用原游戏作为底，在独立副本替换环境与球杆显示、保留已有动态球与规则、重导新桌几何、适配封闭房间内的相机，再做烘焙和 Windows 交付。

Blender 的 `Gameplay preview | Balls - exclude from static room export` 集合只作制作预览。后续静态环境导出必须排除这些球，由原游戏状态创建运行时球；否则会出现两套球。指定球杆单独导成 cuePrefab，不能把当前世界位置的瞄准姿态一起烘进 Prefab。`unity_asset_roles.json` 已列出导出角色。
